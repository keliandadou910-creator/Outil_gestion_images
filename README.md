# Outil de Gestion d'Images — POO Java L2

Application JavaFX de gestion de bibliothèque d'images avec filtres, tags et chiffrement.

# 1) Prérequis

- Java 17 ou supérieur 
- Maven 3.8+

# 2) Lancer l'application

Ce projet utilise Maven pour la gestion automatique des dépendances (JavaFX).

# Via IntelliJ

1. Ouvrez le projet dans IntelliJ IDEA (en chargeant le sous-dossier "Projet" qui contient le "pom.xml").
2. Laissez IntelliJ synchroniser le projet et télécharger les dépendances en arrière-plan.
3. Allez dans `src/main/java/fr/univ/imagemanager/App.java`.
4. Cliquez sur le bouton "Play" (Run).


# 3) Utilisation de l'application

**Ouvrir une image** 
-> Menu **Fichier → Ouvrir** ou **Ctrl + O**

**Sauvegarder l'image** 
-> Menu **Fichier → Sauvegarder** ou **Ctrl + S**

**Appliquer un filtre** 
-> Cliquer sur un bouton dans le panneau de gauche (Filtre)

**Rotation / Symétrie** 
-> Boutons dans le panneau de gauche (Transformations)

**Chiffrer / Déchiffrer** 
-> Boutons dans le panneau de gauche (Sécurité), un mot de passe sera demandé

**Ajouter un tag** 
-> Taper le tag en bas de la fenêtre + cliquer **Ajouter** ou appuyer sur **Entrée**

**Supprimer un tag** 
-> Cliquer sur le tag (bouton avec ×)

**Réinitialiser l'image** 
-> Menu **Fichier → Réinitialiser** ou **Ctrl + Z** ou bouton **↩**
